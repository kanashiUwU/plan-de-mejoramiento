**Día 1 – Teoría del color:**
Aprendí cómo funcionan los colores y las diferentes combinaciones que se pueden utilizar en una página web. También entendí que los colores no se deben escoger solamente por gusto, sino pensando en la función que tendrán en la interfaz.

**Día 2 – Paleta y contraste:**
Aprendí a crear una paleta de colores para el proyecto y a revisar que exista un buen contraste entre el texto y el fondo. También conocí la importancia de la accesibilidad.

**Día 3 – HTML5:**
Aprendí a estructurar una página utilizando HTML5 y sus etiquetas semánticas. Entendí que una buena estructura facilita la organización y comprensión del contenido.

**Día 4 – CSS:**
Aprendí los conceptos básicos de CSS, como los selectores, márgenes, rellenos, bordes y el modelo de caja. También practiqué cómo darle estilo a una página.

**Día 5 – Flexbox y Grid:**
Aprendí a organizar los elementos de una página usando Flexbox y CSS Grid. Esto me ayudó a crear estructuras más ordenadas para el dashboard.

**Día 6 – Diseño responsive:**
Aprendí a adaptar una página para diferentes tamaños de pantalla, principalmente celulares, tabletas y computadores. También trabajé con componentes y menús adaptables.

**Día 7 – JavaScript:**
Aprendí las bases de JavaScript, como variables, funciones, arreglos, objetos y diferentes métodos para trabajar con datos. También aprendí a realizar operaciones con los datos del proyecto.

**Día 8 – DOM y formularios:**
Aprendí a utilizar JavaScript para modificar elementos de la página, manejar eventos y validar formularios antes de enviarlos. También comprendí la importancia de no confiar solamente en las validaciones del navegador.

**Día 9 – PHP y PDO:**
Aprendí cómo conectar PHP con MySQL utilizando PDO y sentencias preparadas. También entendí mejor cómo se comunican el navegador, PHP y la base de datos.

**Día 10 – Inicio de sesión seguro:**
Aprendí a crear un sistema de registro e inicio de sesión utilizando contraseñas protegidas mediante hash. También conocí algunas medidas para proteger los formularios y evitar ataques comunes.

**Día 11 – Sesiones y permisos:**
Aprendí cómo mantener la sesión de un usuario y controlar qué partes del sistema puede utilizar dependiendo de su rol. También aprendí a proteger las páginas privadas.

**Día 12 – Dashboard:**
Aprendí a convertir la estructura del dashboard en una parte funcional del sistema. Trabajé con un menú lateral y con información obtenida de la base de datos.

**Día 13 – CRUD:**
Aprendí a realizar las operaciones principales sobre los datos: crear, consultar, editar y eliminar registros. También aprendí a validar los datos y cuidar la relación entre las tablas.

**Día 14 – Vistas SQL y gráficos:**
Aprendí qué son las vistas en una base de datos y cómo utilizarlas para organizar consultas. También aprendí a mostrar la información mediante gráficos utilizando Chart.js.

**Día 15 – Reportes y sustentación:**
Aprendí a generar reportes con tablas, totales, gráficos y la identidad del proyecto. También aprendí cómo preparar y presentar la aplicación completa durante la sustentación final.
